# KB-Layout
Программа для отображения текущего языка клавиатуры в верхнем правом углу экрана при нажатии любой клавиши.

## Описание

Программа отслеживает нажатия клавиш и отображает текущий язык раскладки клавиатуры (EN, RU и другие) в виде индикатора в верхнем правом углу экрана. Индикатор появляется при нажатии любой клавиши и автоматически скрывается через 1.5 секунды.

## Установка зависимостей

```powershell
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

Программа запустится и будет работать в фоновом режиме. При нажатии любой клавиши в верхнем правом углу появится индикатор текущего языка клавиатуры.

Для завершения работы программы используйте диспетчер задач или закройте окно (если оно видимо).

## Создание исполняемого файла

Для создания исполняемого .exe файла используйте PyInstaller:

**Вариант 1: Использовать скрипт сборки**
```powershell
.\build.ps1
```

или

```powershell
.\build.bat
```

**Вариант 2: Ручная сборка**
```powershell
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "kb-layout" main.py
```

После сборки исполняемый файл будет находиться в папке `dist\kb-layout.exe`

## Поддерживаемые языки

Программа поддерживает следующие языки:
- EN (Английский)
- RU (Русский)
- DE (Немецкий)
- FR (Французский)
- IT (Итальянский)
- CZ (Чешский)
- PL (Польский)
- PT (Португальский)
- KO (Корейский)
- JA (Японский)
- ZH (Китайский)
- NL (Голландский)
- И многие другие...

Если язык не распознан, будет показан его код в шестнадцатеричном формате.

## Требования

- Windows 10/11
- Python 3.7 или выше
- Установленные зависимости из requirements.txt
